# 10 · 设备预测性维护

## 解决什么问题
工厂设备突然停机，损失按小时算；定期保养又常常"没坏也拆"。中间那条路是用振动、温度这类信号判断设备退化到什么程度，提前安排更换。这个工程走通从信号到结论的最小闭环。

## 怎么实现
- `VibrationSim`：生成随磨损逐步放大的振动序列
- `features()`：一个窗口内算 RMS（有效值）、峰值、峭度，三个都是判断冲击/磨损的常用量
- `health_score()`：以 RMS 相对基线的增长做指数衰减，映射到 0–100 的健康分
- `rul()`：按健康分线性外推剩余可用周期，给出粗略换件时间

## 跑起来
```bash
python3 src/phm.py                          # 100 步监测，看健康分趋势
python3 -m unittest discover -s tests -v    # 6 项
```

## 验证
6 项单元测试覆盖：RMS/峰值/峭度的计算、健康分随 RMS 上升而下降、RUL 单调性、边界裁剪（0–100）。

## 边界
- 信号是仿真，健康分是经验公式，RUL 是线性外推，不是训练出来的模型
- 没有轴承故障特征频率（BPFO/BPFI）、频谱分析与标注数据，也没有上线后的漂移监控
