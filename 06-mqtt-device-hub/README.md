# 06 · MQTT 设备接入与物模型

## 解决什么问题
设备一直上报数据，平台侧要同时回答三个问题：这条数据合不合法（字段对不对）、这台设备现在是什么状态、有没有越过阈值要告警。散着写会让每个业务各判一遍。这个工程把这三件事抽成平台组件。

## 怎么实现
- `ThingModel`：定义设备有哪些属性，上报里出现未知字段直接拒收并返回非法字段名
- `DeviceShadow`：按设备合并最新上报值，随时能取到"当前状态"
- `RuleEngine`：按 `(字段, 比较符, 阈值, 级别)` 规则实时判定，命中即产出告警
- `DeviceHub.ingest()`：把校验、影子更新、告警、遥测入库串起来

## 跑起来
```bash
python3 src/hub.py                          # 三条上报：正常、越界告警、非法字段
python3 -m unittest discover -s tests -v    # 4 项
```

## 验证
4 项单元测试覆盖：合法上报入库、非法字段拒收、影子合并、阈值触发告警。

## 边界
- 没有 MQTT broker 连接与报文编解码，只做平台侧的数据模型与规则
- 存储是内存列表，没有持久化、分区、保留策略；规则只支持单字段大于/小于
