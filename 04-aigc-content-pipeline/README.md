# 04 · AIGC 内容管线

## 解决什么问题
内容团队批量用 AI 出图文/短视频时，常见三件事：提示词散在各人手里、批量任务没有状态、发出去之前没人把关合规。这个工程把流程固化成一条管线：模板渲染 → 批量任务 → 生成 → 合规审核 → 结果导出。

## 怎么实现
- `render_prompt()`：把 `{product}`、`{platform}` 这类占位填成具体值，模板集中管理
- `mock_generate()`：可插拔生成后端，当前是本地替身；换成文生图/文生视频 API 只改这一个函数
- `moderate()`：违禁词命中即拦，任务状态置为 `blocked`
- `run()`：逐个任务跑完，返回任务、生成内容与审核结论

## 跑起来
```bash
python3 src/pipeline.py                     # 两条任务，一条通过一条拦截
python3 -m unittest discover -s tests -v    # 5 项
```

## 验证
5 项单元测试覆盖：模板占位替换、生成结果非空、违禁词拦截、正常内容放行、任务状态流转。

## 边界
- 生成是本地替身（截断回显），不调用真实模型；审核只有几条关键词，不是真正的风控
- 没有任务队列持久化、重试、并发和成本核算，也没有素材存储与导出格式处理
