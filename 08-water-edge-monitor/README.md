# 08 · 智慧水务边缘监测

## 解决什么问题
电池供电的水表/流量计，靠一节电池跑几年，不可能一直上报。于是要把"聪明"放到设备端：本地判断数据是否异常，正常就低频上报，异常才立刻发，既省电又不漏事件。

## 怎么实现
- `SensorSim`：生成带缓慢漂移和周期性尖峰的流量序列，用来验证检测逻辑
- `EWMA`：指数加权移动平均 + 方差跟踪，偏差超过 k 倍标准差判为异常
- `LowPowerPolicy`：按休眠周期与唤醒时长算占空比，估算功耗量级
- `report()`：拼紧凑上报包并给出字节数，约束单包大小

## 跑起来
```bash
python3 src/monitor.py                      # 25 个采样点，看哪些触发上报
python3 -m unittest discover -s tests -v    # 4 项
```

## 验证
4 项单元测试覆盖：尖峰被识别为异常、平稳段不误报、占空比计算、上报包字节数。

## 边界
- 数据是仿真信号，EWMA 是统计方法不是模型；真实设备上还要做温漂补偿与阈值标定
- 占空比只是算术估算，没有实测电流、休眠唤醒开销与通信功耗
