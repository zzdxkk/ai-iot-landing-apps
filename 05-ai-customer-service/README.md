# 05 · AI 客服工单助手

## 解决什么问题
客服每天大量重复问题（退款、发票、物流），答案其实都在知识库里；但工单还得手填，信息不全又得来回问。这个工程把「问 → 判意图 → 抽关键信息 → 给答案 → 建单或转人工」串成一条链路。

## 怎么实现
- `intent()`：按知识库条目匹配意图，命中不了归为"其他"
- `slots()`：正则抽手机号与订单号，抽不到就标记
- `handle()`：命中知识库直接回答案；退款类缺订单号、或意图不明时置 `need_human=True`；每张工单生成 `T0001` 形式的编号

## 跑起来
```bash
python3 src/service.py                      # 三条咨询，看工单 JSON
python3 -m unittest discover -s tests -v    # 4 项
```

## 验证
4 项单元测试覆盖：意图命中、未命中转人工、订单号槽位抽取、工单编号递增。

## 边界
- 意图是关键词匹配，不是分类模型；槽位只有两个正则，复杂表述抽不到
- 知识库写死在代码里，没有后台维护界面；没有对接 CRM、消息渠道与工单状态机
