# 07 · Modbus 工业协议网关

## 解决什么问题
工业现场设备讲 Modbus（串口 RTU 或以太网 TCP），平台侧讲 MQTT/HTTP。中间需要一个网关把字节流转成带工程量、带名字的数据，而且帧一错就得当场发现，不能把脏数据往上送。

## 怎么实现
- `crc16()`：手写 CRC16-Modbus（多项式 0xA001），组帧与校验共用
- `build_rtu()` / `parse_rtu()`：RTU 帧的组与解，校验失败标记 `valid=False`
- `parse_tcp()`：解析 7 字节 MBAP 头（事务号、协议号、长度、单元号）与功能码
- `RegisterMap`：寄存器地址 → 字段名 + 缩放系数，把原始整数还原成工程量（如 256 × 0.1 = 25.6）

## 跑起来
```bash
python3 src/modbus.py                       # 组帧、校验、寄存器解析
python3 -m unittest discover -s tests -v    # 5 项
```

## 验证
5 项单元测试覆盖：CRC 标准测试向量、RTU 组帧回读一致、篡改后校验失败、MBAP 头解析、寄存器缩放。

## 边界
- 没有真实串口/socket 收发，也没有多从站轮询调度与超时重发
- 不处理异常响应（功能码 0x80 + 异常码），不支持写寄存器与批量读取优化
